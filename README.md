# Birthday Wish Generator

A simple and friendly chatbot-style app that generates personalized birthday wishes based on the birthday person's name, relationship, tone, age, and any extra details.

## Features
- Interactive chat-style experience
- Choose a tone such as funny, heartfelt, sweet, or short
- Add optional age or extra details
- Generate a polished birthday wish instantly

## Tech Stack
- Python
- Streamlit

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Birthday-Wish-Generator.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Birthday-Wish-Generator
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Run the App
```bash
streamlit run app.py
```

Then open the local URL shown in the terminal, usually:
```text
http://localhost:8501
```

## Example
You can input details like:
- Name: Aisha
- Relationship: friend
- Tone: sweet

The app will generate a warm birthday message for you.
